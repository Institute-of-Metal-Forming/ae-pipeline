# Specs

This directory contains feature specs to be read by developers and AI to cretae features as well tests from.
The specs are sequentially numbered.

Naming convention of documents in this folder must follow: `0001-some-short-title.md`.

Each spec has a header (status, module), a summary, inputs, outputs, parameters, numbered requirements (referenced as `R<n>`, or `<spec> R<n>` from other specs, code reviews and tests, e.g. `0004 R2`) and open questions.
Requirements describe the behavior the implementation must have; open questions list cases that the spec doesn't decide yet.
