# AA Data Directory

> ![NOTE]
> AA means *as aquired*.

Place here the data files aquired from the Vallen AE Suite Software, namely:
- `*.pridb` primary data files
- `*.tradb` transient recording data files

Both file types are in fact just SQLite databases.

The datasets are collected and named by the `*.pridb` files.
For each `*.pridb` file, there must be a corresponding `*.tradb` file of same name.
